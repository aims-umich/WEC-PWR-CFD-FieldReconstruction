Why this release exists

Turning scattered public information into a reusable computational model

Detailed, simulation-ready commercial reactor models are difficult and time-consuming to reconstruct. This project assembles publicly available reactor geometry and operating information into open CAD, CFD, postprocessing, and analysis resources so researchers can begin from a shared technical foundation instead of rebuilding the same infrastructure independently.

Public-source provenance

Built from public technical sources, not proprietary plant design data

A central contribution of the project is the transformation of publicly available but dispersed reactor information into a directly reusable computational model.

The geometry and operating representation were developed from public reactor benchmark information and U.S. government technical documentation. Detailed source citations and methodology are provided in the associated peer-reviewed paper and repository documentation.

From vessel-scale flow to assembly-level data

Research uses

A shared reference model for work beyond the original study

The open release is intended to support reuse, comparison, and extension by researchers with different methods and research questions.

Thermal-hydraulics

Core-inlet flow distribution, turbulence-model comparisons, and high-fidelity reactor CFD.

Benchmarking & verification

Cross-code comparisons, mesh studies, reproducibility, and transparent method evaluation.

Reduced-order modeling

Surrogate models, operator learning, POD-style methods, and computational acceleration.

Machine learning

Field reconstruction, sparse-sensor inference, and data-driven transient modeling.

Digital twins & multiphysics

Common geometry and data foundations for coupled-model and digital-twin research.

Education & collaboration

Realistic reactor resources for students and collaborative studies across universities, laboratories, industry, and international institutions.

Open collaboration

Lowering barriers across institutions and national boundaries

Common open reference models make it easier for research groups to compare methods, reproduce results, validate new approaches, and build on one another's work. The broader objective is to support transparent collaboration toward the safe and peaceful advancement of nuclear technology.

Project context

Part of a broader reactor-analysis research program

This repository supports a broader Nuclear Energy University Program effort combining CFD, neutronics, detector data, and machine learning for reactor analysis and licensing research. The current open release focuses on the computational resources and workflows that are available now.

Software distributed directly through the repository is provided under the repository license. Native STAR-CCM+ files require compatible Siemens software; see the public model archive for applicable model-file information and reuse terms.
